# Security

This project handles API credentials and training/health data. Do not include secrets, personal activity files or private calendar snapshots in a public issue.

For a potentially sensitive vulnerability, contact the maintainer through [their GitHub profile](https://github.com/askeer25) using an available private contact method. A dedicated private advisory channel and response SLA are not currently advertised. If no private contact is available, open a minimal issue requesting contact without publishing exploit details or private data.

If an API key has been exposed, revoke or regenerate it in Intervals.icu settings. Clearing local credentials does not revoke the remote key.

See [privacy notes](docs/privacy.md) for credential storage, local artifacts and the personal-account deployment boundary.
